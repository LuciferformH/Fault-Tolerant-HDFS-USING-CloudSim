# Fault-Tolerant-HDFS-USING-CloudSim
CloudSim 3.0.3 – A Java-based cloud computing simulation toolkit by the Cloudbus Lab, University of Melbourne. Models datacenters, VMs, cloudlets, brokers, and power-aware VM migration. Supports time/space-shared scheduling, network topology, and PlanetLab workloads. Built with Ant/Maven. LGPL licensed.
